# 🐔 El Pollo Loco - Jump'n'Run Adventure An action-packed 2D platformer featuring charming pixel-art characters, strategic boss battles, and responsive gameplay. Built with vanilla JavaScript following clean code principles. --- ## 🚀 Live Demo 🔗 [Live Demo – el-pollo-loco.dev2k.org](https://el-pollo-loco.dev2k.org/) --- ## 📸 Preview ![Game Screenshot](./img/preview-el-pollo-loco.png) --- ## 🎮 Gameplay Control **Pepe** through a desert world, collect coins & bottles, defeat chicken mobs, and challenge the final boss! **Key Features:** - 🕹️ Dynamic mechanics with jump/throw combos - 🎭 5+ character animations (Idle, Jump, Hurt, Dead) - 🐓 3 enemy types + unique boss behavior - 📊 Interactive status bars for health/coins/ammo - 🔊 Immersive SFX & background music - 📱 Mobile touch controls & responsive design - 💾 Local storage for sound settings --- ## 🛠️ Technologies ![JavaScript](Link image) ![HTML5](Link image) ![CSS3](Link image) - **OOP architecture** with separated concerns - **Canvas-based rendering** for smooth animations - **Modular audio system** with random sound pools - **Device orientation detection** - **JSDoc documentation** for core classes --- ## ▶️ Installation 1. Clone repository: ```bash git clone https://github.com/KosMaster87/El-pollo-loco ``` 2. Open in browser: ```bash cd El-pollo-loco && open index.html ``` --- ## 📁 Folder Structure ```text el-pollo-loco/ ├── audio/ # Audio assets │ ├── boss/ # Boss sounds │ ├── environment/ # Coins, bottles │ └── character/ # Pepe sounds │ ├── fonts/ # Custom webfonts │ ├── creepster.woff2 # Title font │ └── lexend.woff2 # UI font │ ├── img/ # Visual assets │ ├── characters/ # Pepe animations │ ├── enemies/ # Chicken sprites │ ├── ui/ # Interface elements │ └── backgrounds/ # Parallax layers │ ├── js/ # Core logic │ ├── models/ # Class definitions │ │ ├── Character.js # Player logic │ │ └── Endboss.js # Boss AI │ │ │ ├── core/ # Game engine │ └── utils/ # Helper functions │ ├── out/ # Generated files │ ├── docs/ # JSDoc output │ └── tests/ # (Planned) unit tests │ ├── style/ # Styling │ ├── components/ # UI components │ └── animations.css # Keyframe animations │ └── index.html # Entry point ``` --- ## 📁 Next Stuff
